# feedback.md Format

`work/hw-N/feedback.md` — written at the homework-feedback pass, after the learner's submission, never before ([SKILL.md](SKILL.md#homework)). This is the journey's only channel for detailed feedback on the learner's own work, which is why its shape is contractual rather than left to taste.

## The elements

| Element | Rule | Why |
| --- | --- | --- |
| Grade / score / level | Never — no number, letter, band, or normative comparison | The zero-stakes firewall; the feedback factor measures ~6× the grade factor, and a grade beside feedback suppresses the feedback |
| Task-level correction | Only for faulty interpretations — a wrong reading of what the task asked | Where knowledge is missing rather than misread, instruction beats feedback |
| Elaboration | What the work shows, how it does it, why it works or fails — elaborated over bare correction | High-information feedback ~0.99 vs corrective ~0.46 |
| Volume | Manageable units — the few things that matter, never everything found | Too much feedback within a level detracts |
| Forward move | Exactly one — the explicit next question the work points to, never an exhaustive audit | Feedback is for the next attempt, not a verdict on this one |
| Praise | None — what the work does well is stated as information, not compliment | The compliment sandwich — person-praise opening a correction — measured *worse* than the correction alone (0.09 vs 0.34) |
| Register | Informational: state what the work shows and what the next move enables — never "you should", "you need to" | Controlling grammar turns information into evaluation |
| Medium and moment | Written, into `feedback.md`, after the attempt only | The artifact is the loop; feedback before an attempt is instruction mislabeled |

**The gap test's carve-out**: a *small* gap is taught inline in the feedback ([SKILL.md](SKILL.md#homework)) — that is instruction riding the artifact, not task-level correction; the correction row does not forbid it.

## Timing is a rationale, not a dial

Two regimes, both deliberate: in-lesson exercises get immediate after-attempt feedback via the reveal gate — the right cell for difficult new material; homework gets inherently delayed feedback, arriving when the next orient scan finds the submission — the right cell for transfer, and transfer is what homework is for. There is no lever here.
