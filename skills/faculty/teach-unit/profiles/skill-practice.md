# Profile: skill-practice

Math/proofs, programming, tool procedures — anything mastered by doing. The spine is the fade: model the skill, then hand it over in steps.

## Lesson shape

Worked example first, every step annotated for *why* — **subgoal labels live on worked examples only, never in expository prose**, and their abstraction keys on prior knowledge: abstract for a learner with the background, feature-tied for one without. Then the learner performs with the scaffold fading.

**The label-pairing rule has a direction**: given labels pair with changed-context practice; learner-generated labels pair with same-context practice. Generated labels *plus* changed context is the collapsed cell — both loads at once.

## Exercise ladder

Completion (partial solution, supply the missing steps) → find-the-flaw (a wrong proof / buggy code / broken procedure to diagnose) → full independent production. **Interleave problem types** across the set — picking the technique is telling confusables apart, the case the core's interleaving rule licenses. Fade position on the ladder moves on retrieval evidence, nothing else.

The solution shipped with an exercise names **the one or two ideas it turns on** — an answer key alone shows the steps and not the reason for them. On the find-the-flaw rung the flaw *is* the near-miss, staged before the attempt instead of after it.

## Recall-item shapes

State the definition / theorem / command from memory; short full production ("prove X", "write the function", "run the recovery"); which-technique-applies-and-why discrimination items. Production over recognition, always.

## Named instruments

- **(code)**: predict-before-you-run and trace-before-write — generation before telling, both directions; Parsons reorder (scrambled numbered lines to re-sequence) **only where the intended solution is the one the learner would naturally write** — contested idiom or many natural solutions → have them write the code; subgoal-labeled examples. The workspace runs — exercises are literally runnable, use that.
- **(procedure)**: retrieval = **re-performing the task** on a prepared scenario, then a variation ("now X differs"); procedures decay fast — space tighter; pair every step with its why so the procedure survives novel situations.
