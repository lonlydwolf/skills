# Profile: vocabulary

Terminology, API surface, natural-language vocab. The one profile that changes the **artifact set**: add a deck, thin the lesson prose.

## Lesson shape

Thin by design — a short usage frame around the deck; the deck is the central artifact, the lesson exists to put the terms in context.

## Exercise ladder

Cued recall **both directions** (term→meaning, meaning→term) → relearn to criterion within the session → usage-in-context production ("use these five terms correctly in a paragraph / code comment") once recognition holds.

## Recall-item shapes

Cued recall, both directions, spaced across future units via the retrieval pool — vocabulary is the pool's best customer. Recognition-only items (matching, multiple-choice) are the floor, never the method.

## Named instruments

The **deck** — `lessons/deck.html` ([DECK-PAGE.md](../DECK-PAGE.md)), learner-facing like every practice instrument; the term/definition source the recall page regenerates from. Expanding spacing; successive relearning (recall to criterion this session, again across sessions).
