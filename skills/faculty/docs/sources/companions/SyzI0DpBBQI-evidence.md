# Retrieval, explanation and useful difficulty

[Video synthesis](../SyzI0DpBBQI.md)

[Repeated retrieval research](https://www.science.org/doi/10.1126/science.1152408) and a [research review](https://pmc.ncbi.nlm.nih.gov/articles/PMC7461852/) support retrieval practice in many settings. Effective questions target the intended capability, feedback repairs errors, and later or varied prompts help distinguish retention from item familiarity.

A [self-explanation meta-analysis](https://eric.ed.gov/?id=EJ1186664) supports generated explanation as a learning activity. Fluent explanations can still be wrong: inspect mechanism, dependencies, examples, limits and connection to formal language.

[Deliberate-practice meta-analysis](https://doi.org/10.1177/0956797614535810) finds meaningful but partial associations with performance, varying by domain and definition. A useful task identifies a performance component, a standard, feedback, a corrected repetition and adjusted difficulty.

Difficulty is desirable when it improves the target under suitable conditions. Confusion, inaccessible prerequisites or unsupported mistakes are not valuable merely because they feel hard. Scaffolding can be appropriate. There is no universal forgetting curve or fixed study-time advantage.

The exact modern four-step Feynman Technique attribution was not established in ingestion. Call the operative behavior self-explanation with gap repair. Faculty should use an adaptive attempt → feedback → repair → retry → later application loop rather than guarantee a speedup.
