# Context, schemas and reading comprehension

[Video synthesis](../mbCAOQfBrlk.md)

[Bransford and Johnson's 1972 paper](https://memlab.yale.edu/sites/default/files/files/1972_Bransford_Johnson_JVLVB.pdf) shows how appropriate context can improve comprehension and recall for selected ambiguous material. The laundry demonstration does not establish an effect size for every ordinary text.

[Hattan's review](https://journals.sagepub.com/doi/abs/10.3102/00346543221148478) examines prior-knowledge activation. Relevant knowledge needs sufficient amount, accuracy and specificity; activating a misconception can interfere with comprehension.

[Oded and Stavans](https://www.sciencedirect.com/science/article/abs/pii/0346251X9490006X) addresses false-schema activation. These are the bibliography's authors; the captions' different names are an error. Misleading framing can distort interpretation, with outcomes dependent on reader and text conditions.

[Dunlosky and colleagues](https://journals.sagepub.com/doi/10.1177/1529100612453266) reviews learning techniques broadly. It does not directly validate Preview–Predict–Purpose as a universal package.

Use preview → provisional prediction → purpose → read → recalibrate → retrieve. Label external framing, include an alternative and disconfirming cue, bridge unfamiliar background and let learners choose spoiler depth. Verify comprehension through evidence-grounded explanation and application, not a feeling that the text makes sense.
