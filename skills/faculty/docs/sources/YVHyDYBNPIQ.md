## Contribution

The source argues for a main area of depth with selected supporting skills, linking breadth through shared mechanisms and integrated projects. Its useful distinction is between accumulating topics and building combinations that serve an actual capability.

## Faculty application

- Start from a primary learner goal and include supporting knowledge only when useful.
- Budget breadth so unrelated topics do not displace required practice.
- Ask the learner to demonstrate a connection in an artifact or changed context.
- Examine the structure and limits of an analogy before using it to infer something.

## Evidence boundaries

Far transfer is uncertain. Chess or broad reading does not automatically improve general intelligence, and a proficiency percentage without a valid assessment is not evidence. The value of specialization depends on the task. Roommate can explore unusual connections, but exploration neither certifies transfer nor changes course progression.
