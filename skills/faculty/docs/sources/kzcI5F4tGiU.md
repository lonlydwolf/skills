## Contribution

A personal teaching configuration uses Probe → Plan → Teach: identify the learner's current boundary, clarify the desired capability, construct prerequisites and teach through motivated steps. Its companion repository demonstrates learner-specific persistent artifacts and dedicated research/visual workers.

## Faculty application

- Separate goal clarification from diagnostic assessment.
- Use prerequisite relationships to choose reachable next steps.
- Combine guided discovery with explanation when unaided discovery is unreasonable.
- Distinguish confidence or a subjective “click” from demonstrated understanding.
- Use worker outputs only after completion and acceptance.

## Evidence boundaries

The repository is a personal implementation shared for adaptation. Its exhaustive probing, binary-search metaphor and universal-foundation language are not required Faculty policy. Multiple-choice success can miss reasoning gaps; subagents can share the same errors. No long-term learner outcome was established. The recorded snapshot is historical, not a claim about the repository today.
