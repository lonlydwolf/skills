# Skills

This is a collection of skills I use in my own work. You're welcome to use them, share feedback and contribute improvements.

| Collection | What you can do |
|---|---|
| [Faculty](skills/faculty/README.md) | Build a course around a learning goal, practice with a Teacher, demonstrate understanding and get feedback on what you build. |
| [In progress](skills/in-progress/README.md) | Try skills that are still being tested: audit a repository, have a second model review finished work, and file pull requests that show what changed, what was verified and what merging risks. They may change. |

Install with:

```sh
npx skills@latest add lonlydwolf/skills
```

Choose your preferred tool and the skills you want. In-progress skills are independent, so install any of them alone. Faculty is currently in beta and requires all seven skills in its group. See [installation](skills/faculty/docs/INSTALL.md) for setup and updates, or the [Faculty guide](skills/faculty/README.md) for the course workflow.

Found a problem or have an improvement? [Open an issue](https://github.com/lonlydwolf/skills/issues) or read [Contributing](CONTRIBUTING.md) to propose a change.
